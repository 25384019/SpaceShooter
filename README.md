# Space Shooter: Odyssey v3.5 (太空探索 Roguelite 架构版)

一款基于 **团结引擎 (Tuanjie 1.10.2 / Unity 2022.3 URP)** 构建的轻量级太空探索 Roguelite 游戏。
遵循**「零新素材、纯原生 Unity 引擎能力与对象池零 GC 优化」**原则，将纯飞机射击全面升级为包含**太空战斗、母舰星图航线、战略能源管理、未知星球全息扫描与任务契约**的星际探索体验。

---

## 🚀 3.5 核心系统与全新架构

### 1. ⚡ 战略能源与跨场景档案 (Strategic Energy & PlayerProfile)
- **全局战略能源 (0~100⚡)**：能源不仅是护盾或跳跃成本，更是决定每一次行动的核心制约资源！
- **行动能耗**：
  - 全息扫描未知星球：-5⚡
  - 尝试登陆星球：-10⚡
  - 空间跃迁返航母舰：-12⚡
  - 航线巡航消耗：安全航线 -8⚡、暴雨富矿带 -12⚡、旗舰猎杀深空 -18⚡
- **局内外通用货币 (Credits)**：通过完成悬赏任务与勘探未知星球获取，支持本地存档持久化。

### 2. 🪐 星球遭遇与全息扫描系统 (Planet Encounter & Scan)
- 击败星区旗舰或完成波次巡航后，眼前浮现庞大神秘的未知星球轮廓；
- **全息能量扫描**：消耗 5 点能源扫描，揭示星球代号（如 Kepler-186f、LV-426）、危险星级、资源富集度与地表气候环境（极寒冰原/废墟遗迹/烈焰荒漠/剧毒沼泽）；
- **战略抉择**：
  - **[ PREPARE LANDING (-10⚡) ]**：进入大气层勘探，获得丰厚信用点奖励并为 v4.0 地面探索奠定基石；
  - **[ WARP RETURN BASE (-12⚡) ]**：带着战利品平安返航母舰。

### 3. 📜 动态赏金任务契约 (Mission Contract System)
- 每次出航动态生成契约（陨石清理、旗舰悬赏、护盾能量核心打捞）；
- 局内战斗 HUD 实时追踪契约进度（如 CONTRACT: [8/12] ASTEROID SWEEP）；
- 达成后即刻发放丰厚能源补给与大额信用点奖励。

### 4. 🗺️ 母舰星图航线调度 (Star Map Navigation)
- 支持按键 **M** 或点击屏幕右上角 **[M] STAR MAP** 随时调出星图航线；
- 提供 **路线 A（安全星区）**、**路线 B（陨石风暴富矿带）**、**路线 C（深空旗舰猎杀）** 三种不同难度与回报的跃迁路线。

### 5. ⚔️ Space Combat 核心太空战斗模块
- **Boss 战旗舰决战**：巡航直射与狂暴 3 向散射弹幕，召唤护卫小型陨石，顶部自适应血条，连环大引爆与终极强震。
- **关卡多波次演进**：Wave 1 遭遇 $\to$ Wave 2 极速陨石暴雨 $\to$ Wave 3 旗舰大决战 $\to$ 星球遭遇。
- **多重射击与护盾光环**：单发、双联与三向散射；原生呼吸脉冲护盾吸收伤害。
- **工业级零 GC 对象池**：子弹、敌军激光与各规格陨石全生命周期池化，彻底消灭运行期垃圾回收顿挫。

## 🕹️ 操作指南

| 操作 | 对应按键 |
| :--- | :--- |
| **战机移动** | W / A / S / D 或 方向键 ↑ ↓ ← → |
| **射击** | 空格键 (Space) / J 键 / 鼠标左键 |
| **武器手动切换** | 主键盘数字键 **1**（单发）/ **2**（双发）/ **3**（三发） |
| **呼出 / 关闭星图** | 按键 **M** 或点击右上角 **[M] STAR MAP** 按钮 |
| **星球全息扫描** | 点击屏幕下方扫描与战略决策按钮（消耗对应能源） |
