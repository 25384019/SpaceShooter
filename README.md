# Space Shooter 2D v2.0 (太空射击避障游戏 2.0 旗舰决战版)

一款基于 **团结引擎 (Tuanjie 1.10.2 / Unity 2022.3 URP)** 构建的高性能 2D 太空射击避障游戏。
遵循**「零新素材、纯原生 Unity 引擎能力与对象池零 GC 优化」**原则构建。

---

## 🎮 2.0 重大更新：核心玩法与系统

### 1. ⚔️ Boss 战旗舰决战系统 (Boss Battle - Dreadnought Flagship)
- **外观气场**：复用飞船材质进行翻转倒悬与暗红装甲涂装（2.3x 威慑比例），伴随全屏红光警报平滑驶入战位。
- **阶段一（HP > 50%）**：正弦波巡航平移，每隔 1.8 秒发射双联直射赤红激光弹。
- **阶段二（狂暴状态，HP ≤ 50%）**：全舰泛起烈焰赤光、移动速度增加 50%、发射 3 向散射弹幕（$-18^\circ, 0^\circ, +18^\circ$），并不定期召唤 2 颗高速小型陨石冲锋护航。
- **专属血条与受击反馈**：屏幕顶部居中实时绘制 ★ BOSS: DREADNOUGHT FLAGSHIP ★ 原生动态血条；受击触发 0.06s 白炽闪烁与微震。
- **连环爆炸终结**：阵亡时触发 5 连环随机爆炸粒子（ExplosionFX）与递进镜头震动，最终震撼大引爆（CameraShake.Shake(0.6f, 0.45f)），爆出 **2 颗护盾道具**并奖励 **+15 大额得分**后通关。

### 2. 🌌 连贯关卡波次推进系统 (Wave Progression)
- **Wave 1：常规陨石带（0~9 分）**：初始星空漫步，常规陨石下落，引导玩家通过得分将武器升级至双发（7 分）。
- **Wave 2：突发随机事件——陨石风暴（10~24 分）**：
  - 积分达 10 分拉响警报 ⚠ WARNING: METEOR STORM INCOMING! ⚠；
  - 背景星空加速至 3.2 倍速高速穿梭，小型极速陨石倾泻而下；
  - 暴雨中段向玩家定向空投 1 颗保命护盾；结束后平稳过渡至 18 分三发枪。
- **Wave 3：Boss 决战（25 分触发）**：
  - 暂停常规杂兵刷新，背景降速至 0.8 倍速，星空变为血战暗红；
  - Boss 降临决战，击杀后结算通关进入胜利界面。

### 3. 🎲 随机事件与战术空投 (Random Events & Supply Drop)
- 由 RandomEventManager 基于概率驱动，支持突发陨石暴雨与战术护盾空投，屏幕居中展示发光警报横幅。

### 4. 🔫 多重射击系统 (Multi-Shot System)
- **Normal**：单发中路直线射击；
- **Dual Shot**：左右双翼对称平行射击；
- **Triple Shot**：中央直射 + 左右两侧小角度扇形散射；
- 随积分自动晋级，或按主键盘 1 / 2 / 3 手动切枪。

### 5. 🪨 三种陨石分级与受击反馈 (Asteroid Variants)
- **Small**：微型极速高机动陨石，1 HP，击破得 2 分；
- **Normal**：标准陨石，1 HP，击破得 1 分；
- **Large**：巨型高血量陨石，3 HP，中弹触发红白高亮受击闪烁与轻微击打微震，击破得 3 分。

### 6. 🛡️ 能量护盾系统 (Shield System)
- 击碎陨石概率掉落能量徽记；拾取后在战机周围激活青蓝色能量护盾环（原生 LineRenderer 呼吸脉冲光环）；
- 碰撞陨石或敌军子弹时免死抵挡一次致命伤害。

### 7. ⚡ 工业级对象池与零 GC (Object Pooling & Zero-GC)
- 玩家子弹、敌军/Boss 子弹、各类规格陨石全部池化循环复用；
- 彻底消灭运行期间高频产生/销毁 GameObject 的开销，高帧率无顿挫。

### 8. 🏆 历史最高分持久化 (Best Score)
- 基于 PlayerPrefs 全局记录最高分与结算得分，并在开始界面、战斗 HUD、胜败结算面板居中展示。
