# Space Shooter 2D (太空射击避障游戏)

一款基于 **团结引擎 (Tuanjie 1.10.2 / Unity 2022.3 URP)** 构建的 2D 太空射击避障游戏。

---

## 游戏特色与核心系统

1. **多重射击系统 (Multi-Shot System)**：
   - **Normal**：单发中路直线射击；
   - **Dual Shot**：左右双翼对称平行射击；
   - **Triple Shot**：中央直射 + 左右两侧小角度扇形散射；
   - 随积分进阶（7 分晋级双发，18 分晋级三发），或按主键盘 `1 / 2 / 3` 手动切枪。

2. **三种陨石分级与受击反馈 (Asteroid Variants)**：
   - **Small**：微型极速高机动陨石，1 HP，击破得 2 分；
   - **Normal**：标准陨石，1 HP，击破得 1 分；
   - **Large**：巨型陨石，3 HP，中弹触发红白高亮受击闪烁与轻微击打微震，击破得 3 分。

3. **原生爆炸粒子与分级震动 (Explosion FX & Camera Shake)**：
   - 原生双层 ParticleSystem 特效：飞溅岩石碎屑与高初速金黄火花；
   - 击毁不同规格陨石与飞船阵亡触发分级独立相机微震动。

4. **能量护盾系统 (Shield System)**：
   - 击碎陨石概率掉落能量徽记；
   - 拾取后在战机周围激活青蓝色能量护盾环（原生 LineRenderer 呼吸脉冲光环）；
   - 碰撞陨石时免死抵挡一次致命伤害并粉碎陨石。

5. **历史最高分持久化 (Best Score)**：
   - 基于 `PlayerPrefs` 持久化记录最高分；
   - 实时比对并激活高亮破纪录横幅（`★ NEW HIGH SCORE! ★`）。

6. **工业级对象池与零 GC (Object Pooling & Zero-GC)**：
   - 子弹与陨石全生命周期池化，彻底消灭运行期 `new GameObject` / `Destroy` 开销；
   - OnGUI 样式与字符串全局缓存，HUD 脏标记按需刷新，消除运行期 GC 停顿。

---

## 操作指南

- **移动**：`W / A / S / D` 或 方向键 `↑ ↓ ← →`
- **射击**：`空格键 (Space)` / `J` 键 / `鼠标左键`
- **武器切换**：主键盘 `1` (单发) / `2` (双发) / `3` (三发)
- **开始/重玩**：`空格键` / `回车键` / `点击鼠标`
